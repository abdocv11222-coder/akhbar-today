# أخبار اليوم
موقع أخبار عربي ثابت يعمل على Vercel، ويستخدم Supabase لقاعدة البيانات وتسجيل دخول المدير وتخزين الصور.

## الملفات
- index.html: واجهة الأخبار العامة.
- admin.html: لوحة تحكم المدير.
- setup_storage.sql: إعداد مخزن الصور وسياساته.

## الإعداد
1. افتح مشروع Supabase ثم SQL Editor.
2. شغّل محتويات setup_storage.sql مرة واحدة.
3. تأكد أن جدول public.news موجود وأن سياسات RLS التي أعددتها سابقًا مفعّلة.
4. افتح /admin.html وسجّل الدخول بحساب المدير الذي أنشأته في Supabase Auth.
5. أضف خبرًا تجريبيًا وانشره، ثم تحقق من ظهوره في الصفحة الرئيسية.

## الأمان
مفتاح Supabase المستخدم في صفحات المتصفح هو Publishable key فقط، وليس Secret key.
صلاحيات قاعدة البيانات وملفات التخزين يجب أن تظل محكومة بسياسات RLS. لا تضع كلمة مرور قاعدة البيانات أو Secret key داخل ملفات الموقع.
